# Be.Vision Products

Be.Vision Core is the reusable platform. Products are thin applications built on top.

## Attendance

Use Core identity and camera events for employee arrival/departure, presence, late/early signals, attendance history and supervisor dashboards.

## Site Security

Use Core perception, identity, zones and policies for restricted-zone alerts, outside-hours presence alerts, repeated access-denied alerts, configurable observable visual signals, operator notification and incident timelines.

The system should not make unsupported claims about intent or criminality. Alerts should reference concrete signals and evidence.

## Visual Analytics

Future applications can reuse the same camera/event foundation for occupancy, traffic/flow, queue monitoring, asset presence and production-line monitoring.

## MakerLens

MakerLens can become an independent product consuming a future generic visual-analysis API. Its object/manufacturing intelligence should not be coupled to identity or security services.
